# LinkPad Releases

- **`LinkPad-Android.apk`** — Pre-built Android APK (`v1.3.0`, `versionCode 2`, debug-signed for immediate sideloading).
- **Windows PC Binaries (`LinkPadHostSetup.exe` & `LinkPadHost.exe`)** — Built natively on Windows runners by [`.github/workflows/release.yml`](../.github/workflows/release.yml) and published directly alongside `LinkPad-Android.apk` on **[GitHub Releases](https://github.com/Nimen-star/linkpad-app/releases/latest)**.

> To publish all three binaries (`LinkPad-Android.apk`, `LinkPadHostSetup.exe`, and `LinkPadHost.exe`) to a GitHub Release right after pushing to GitHub, open **Actions → Build & Publish LinkPad Releases → Run workflow** (or push tag `v1.3.0`).
